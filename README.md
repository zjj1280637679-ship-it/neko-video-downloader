# 🌸 喵喵视频下载姬

Chrome 网页视频发现、HLS 分片下载、带时间戳的原尺寸截图，以及可由 Agent 调用的浏览器控制台。

**1.2.1 候选版**：已通过下列自动化回归，真实 Chrome / 用户站点验收尚未完成。详情见[验证记录](docs/validation.md)。

## 安装扩展：三步

1. 下载本仓库代码并解压，找到包含 `manifest.json` 的文件夹。
2. 在 Chrome 打开 `chrome://extensions/`，开启右上角“开发者模式”，选择“加载已解压的扩展程序”，选中该文件夹。
3. 固定工具栏上的“喵喵视频下载姬”，打开视频网页并开始播放，再点击扩展图标。

更新时在扩展管理页点击重新加载，并刷新已经打开的视频网页，使内容脚本也更新。

## 日常使用

| 功能 | 当前行为 |
|---|---|
| 视频发现 | 结合响应类型、页面视频与地址证据识别媒体；新证据可修正旧判断，目录名称不单独决定隐藏视频 |
| HLS 下载 | 优先最高码率；清单、密钥或初始化段准备失败时尝试已有的其他档位，并显示实际选择；支持已实现的 AES-128、初始化段和字节范围处理 |
| HLS 上下文 | 重定向后的相对地址按最终清单地址解析；密钥格式分别判断，初始化段按声明时的范围、密钥和 IV 处理；TS 输出 `.ts`，fMP4 输出 `.mp4` |
| 分片并发 | 根据实测并发数与总下载速度的趋势计算目标，持续补位；没有固定 5 片限制 |
| 大文件保存 | 可直接写盘时按序写入，用字节缓冲背压控制积压；否则使用内存合并 |
| 取消与错误 | 可取消下载；写盘/网络失败后恢复按钮；全部分片失败不提交空视频 |
| 独立音轨 | 检测后明确提示未合并音轨，可复制音轨清单或原始清单；仍可选择只保存视频流 |
| 视频截图 | 卡片使用小图，预览/保存读取原尺寸 JPEG；无下载地址的 blob/srcObject 播放器也有独立抓拍入口；换源清理，手动同秒抓拍可替换 |
| 播放器选择 | 定向到已登记的播放器文档；多个候选可逐个选择，所选目标失败时保留其错误，避免误取其他画面 |

截图原图暂存在播放器页面内存；换源、刷新或缓存淘汰后需重新抓拍。跨域播放器可能禁止读取视频像素，此时返回明确错误。blob/HLS 的画面标为“当前播放器截图”，不宣称已证明其对应某条清单。

并发目标只由有效的“实际在途分片数—合计接收字节/秒”历史决定。写盘缓冲、重试和下载尾段不作为调高或调低目标的输入；受这些因素干扰的测速窗口不参与拟合。函数、取样口径和边界见[自适应并发说明](docs/adaptive-download.md)。

媒体识别、播放器选择、清单候选与命令结果的判断依据，见[基本能力复查说明](docs/capability-review.md)。HLS 的档位回退发生在下载计划准备阶段；下载中途不会把不同档位的分片混在一起。

## 让 Agent 调用浏览器

在**本机项目文件夹的终端**运行：

```sh
python -m pip install -r requirements.txt
python browser_controller.py --open
```

Windows 也可双击 `启动浏览器云控制台.bat`。控制台默认地址为 `http://127.0.0.1:8899`，会使用专用浏览器数据目录。普通 Chrome 首次需在控制器打开的新窗口中手动加载扩展；程序会给出提示。

在**另一个终端或能执行命令行的 Agent**里运行：

```sh
python agent_cli.py health
python agent_cli.py tabs
```

随后可用通用 CDP 请求导航、读取页面、输入、点击及截图，响应含结果、错误和超时。可视控制台继续支持标签页切换及鼠标键盘操作。

标签页切换在准备成功后才生效；切换失败时原画面仍可操作。前进、后退始终操作发起动作时的标签页。

完整的 Windows / PowerShell 示例、HTTP 接口、接入已开启调试的浏览器、远程连接和验证边界，见 **[Agent 接入说明](docs/agent-bridge.md)**。GitHub 上的代码不会自动连上 ChatGPT；当前交付的是可运行的桥接程序和协议。

## 项目文件

| 文件 | 职责 |
|---|---|
| `manifest.json` | Manifest V3 扩展入口与权限 |
| `background.js` | 媒体状态、持久化、播放器定位与消息路由 |
| `content.js` | 页面发现、视频来源跟踪、缩略图与原图 |
| `popup.html/css/js` | 人工使用的插件弹窗 |
| `downloader.html/js` | HLS 解析、分片下载、取消及保存 |
| `adaptive-concurrency.js` | 总吞吐量响应曲线、趋势上探与局部峰值/平台搜索 |
| `adaptive-download.js` | 实际字节测速、连续补位、有序写入与字节缓冲背压 |
| `browser_controller.py` | HTTP/WS 控制桥与浏览器进程管理 |
| `controller_ui.html/js` | 可视浏览器控制台 |
| `agent_cli.py` | 只依赖 Python 标准库的 JSON 命令行客户端 |
| `tests/` | 明确缺陷与接口行为回归 |

## 测试

```sh
node --test tests/*.test.js
python -m unittest discover -s tests -p 'test_controller*.py' -v
```

Node 测试使用浏览器 API 替身；Python 集成测试使用真实 HTTP/WS 与 mock CDP。它们不代替真实浏览器下载与播放验收。

## 更新记录

### 1.2.1 候选版 · 2026-11-12

- 清单、密钥及初始化段加载可取消；失败或取消后可在原页重新解析，加载期间仍可复制链接和保存原清单。
- 网络连续 30 秒没有收到数据时终止当前请求；分片按原流程重试，本地写盘背压等待不计入网络超时。
- 核对 206 响应的 Content-Range 与长度；服务器返回 200 时，仅从覆盖所需范围的完整数据中切片。错误数据不会交给写盘端。
- 原并发趋势计算保持不变。新增回归与真实 HTTP / 文件解码验证，见[本次验证记录](docs/download-recovery-validation.md)。完整扩展浏览器验收仍待完成。

### 1.2.0 候选版 · 2026-11-11

- 修复保存框取消、写盘异常卡死、重复进度计数及空文件导出路径；增加主动取消。
- 按并发数量与总吞吐量趋势计算目标并持续补位；按序写盘，字节缓冲背压与并发优化分离。
- 检测并说明独立音轨未合并。
- 按响应、页面与地址证据修正媒体类型，避免路径关键词隐藏可用视频；为无下载地址和多个候选播放器保留独立截图入口。
- HLS 按格式选择可用密钥，修复初始化段的范围与加密上下文、重定向地址和候选档位回退；TS 初始化段不再被直接认定为 fMP4。
- 原尺寸截图、换源清理、同秒替换、iframe 定向和来源核对。
- worker 恢复前的新增与清理事件排队，避免旧快照覆盖新状态。
- 新增有明确结果的 HTTP/WS CDP 接口、stdlib CLI、跨平台路径和专用 profile。
- 增加调用鉴权、目标选择、断连/超时报告、回归测试与接入文档。
- 标签页切换成功后提交选择，保留失败前的可用目标；多步导航绑定原目标，CLI 严格检查布尔结果和 HTTP 状态。
