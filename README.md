# 喵喵视频下载姬 · Neko

一个保留樱花与猫咪风格的 Chrome Manifest V3 音视频下载扩展。识别当前页面的媒体地址，提供直接下载、HLS 分片下载与视频截图。

## 安装与更新

1. 下载并解压扩展包，保留解压目录。
2. 在 Chrome 地址栏手动输入 `chrome://extensions/`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的目录。
4. 更新已安装版本时，点击扩展卡片的“重新加载”，再刷新视频页面。
5. 播放目标视频，点击工具栏中的“喵喵视频下载姬”。

`启动并测试插件.bat` 仅打开测试页面并显示安装步骤。Chrome 137 起，官方 Chrome 已不再支持通过 `--load-extension` 自动加载扩展。[Chrome 官方说明](https://developer.chrome.google.cn/blog/extension-news-june-2025?hl=en)。

## 使用流程

- **直接文件**：选择 MP4 / WebM 等媒体后下载；下载状态以 Chrome 实际事件为准。
- **HLS / m3u8**：打开独立下载工作台 → 等待解析清单 → 点击下载 → 选择保存路径。保持工作台打开，完成后用播放器检查音视频。
- **截图**：播放视频后抓拍当前帧；跨域播放器不允许读取画面时会明确提示。截图只在本地处理。
- **切换集数或线路**：当前选中的 `lineData.active` 会被识别；不会把页面上所有未播放集数一次灌入列表。

## v1.2.0 改进

- 分片重试仍失败时终止任务，不再把残缺文件标记为成功。
- 取消保存、取消下载和写盘失败分别处理；成功状态等待真正保存完成。
- 修正 HLS 重定向后的相对路径、AES-128 IV、初始化段缓存与字节范围处理。
- 限制并发缓存，按顺序写入；优先流式写盘。
- 修复后台状态恢复与实时捕获之间的竞争，减少重复扫描和碎片误报。
- 安全渲染网页标题、URL 和预览信息，避免网页内容被解释为界面 HTML。
- 重新整理樱花色界面、来源信息、空状态和进度反馈，减少高频整页重绘。
- 去掉下载工作台不必要的网页公开访问声明；不新增权限。

## 格式与限制

- 支持普通文件、有限长度的 HLS VOD、标准 AES-128 分片加密及兼容的 fMP4 初始化段与字节范围。
- TS 流保存为 `.ts`，fMP4 流保存为 `.mp4`；这是保留原始编码的顺序拼接，不会转码或保证所有播放器兼容。
- DRM / SAMPLE-AES、直播、独立外置音轨或不能安全拼接的清单会明确报错，避免生成缺声或损坏的文件。
- 某些站点依赖特定授权、请求头或短期链接。页面可播放不代表扩展一定能下载；403 / 过期链接会按实际错误报告。
- 直接保存位置选择不可用时，优先写入浏览器专属临时磁盘（OPFS），完成后交给 Chrome 保存；只在这两种磁盘方式都不支持时使用最多 256 MiB 的内存回退。临时磁盘受浏览器配额限制，任务结束后仅清理本任务文件。
- 截图受浏览器跨域画布规则限制。

## 开发验证

无构建步骤；扩展运行时不加载外部 JavaScript。Node.js 20+ 可运行：

```sh
npm test
```

测试覆盖后台捕获/恢复和 HLS 解析、解密、重试、取消、范围请求与有序输出。真实站点验证的日期、样本和边界见 `VALIDATION.md`，浏览器 UI 与 Node 核心验证分别记录。

## 权限

`webRequest` 用于观察媒体响应；`downloads` 用于保存文件和追踪状态；`storage` 用于会话状态；`activeTab` 用于当前页面信息。`<all_urls>` 用于从不同站点识别和请求媒体。媒体记录保存在浏览器会话中，不上传到服务端。

仓库中的 `browser_controller.py` 是旧版独立远程调试实验，不属于扩展运行所需文件，发行扩展包不包含它。常规使用不需要启动控制台或开放调试端口。
