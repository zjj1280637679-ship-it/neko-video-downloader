# 🌸 喵喵视频下载姬 (Neko Video Downloader) 🌸

> **超可爱的 Chrome 网页音视频嗅探与下载神器，一键捕捉 MP4 与 HLS/m3u8 动漫视频，支持切片无损合并与带时间参数的多帧截屏喵~ (◕ᴗ◕✿)**

---

## ✨ 核心特色功能

1. **🌸 极简逻辑与 650ms 极速高频捕捉**：
   * 采用底层网络流量拦截（`chrome.webRequest`）+ DOM 智能扫描双轨机制。
   * 支持多层 `iframe` 深度穿透，无论播放器嵌在多深，缓冲启动瞬间即可秒级捕捉。
   * 650ms 高频实时状态更新与动态雷达脉冲，状态永远保持“正在捕捉中”。

2. **🎬 精彩多帧截屏预览 + 精确时间参数**：
   * 播放时自动对视频进行关键帧采样，生成横向滑动的截屏画廊。
   * 每张截屏左下角均标注清晰的**时间参数标签**（如 `⏱️ 00:05`、`⏱️ 00:28`）。
   * 支持 **【📸 抓拍当前帧】** 实时截取当前秒数画面。
   * 支持点击单帧弹出大图预览，并一键 **保存截图 (JPG)** 到本地。

3. **🛡️ 智能切片碎片拦截过滤**：
   * 专门针对在线视频平台（如 ikanbot、各类流媒体站）的 HLS 播放机制进行了深度优化。
   * 自动过滤并拦截几 MB 的 `.ts` / `.m4s` 短切片碎片，直接锁定**整部完整视频**总流，避免碎片刷屏。

4. **🚀 内置【喵喵切片合并下载姬】**：
   * 解决普通插件遇到 `.m3u8` 只能下载几 KB 空文本的痛点。
   * 在浏览器内并发拉取全部切片，无损合并成完整的视频大文件（500MB~1GB+）导出！
   * 同时提供 **【📋 复制整片直链】**，秒粘贴进 PotPlayer 或 VLC 观看完整影片。

5. **🎀 可爱的二次元萌系动漫 UI**：
   * 樱花粉渐变色系、软萌猫耳 Header、圆角糖果卡片、跳动颜文字表情与微交互动效。

## 🛠️ 安装到 Google Chrome 步骤

1. 打开 **Google Chrome** 浏览器，访问扩展管理页面：
   ```
   chrome://extensions/
   ```
2. 开启右上角的 **【开发者模式】**。
3. 点击左上角 **【加载已解压的扩展程序】**。
4. 选择本项目所在文件夹：
   ```
   cute-anime-video-downloader
   ```
5. 点击 Chrome 右上角拼图图标 🧩，将 **🌸 喵喵视频下载姬** 固定在工具栏即可！

---

## 🎬 实验步骤（以爱看机器人 ikanbot 为例）

1. 打开目标视频页面（例如 `https://www1.ikanbot.com/play/1027358`）。
2. 点击网页上的播放按钮播放视频。
3. 打开插件弹窗：
   * 插件自动过滤几 MB 的短碎片，直接锁定 **【🌸 完整全片流媒体】**。
   * 播放几秒后自动呈现**带时间参数的多帧截屏画廊**。
   * 可点击 **【一键合并下载整部视频】** 保存完整大文件，或点击 **【复制整片直链】** 导入本地播放器观影。
