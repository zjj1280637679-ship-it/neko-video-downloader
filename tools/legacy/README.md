# 历史工具

这里保留1.x附带的Python浏览器控制桥与启动器，供历史对照，不属于2.0扩展运行时，也未纳入本轮验证。2.0无需启动Python服务或调试端口。

历史启动器原本依赖旧目录布局，迁移后不要直接用它安装2.0。请按仓库README加载扩展包。

公开副本已移除个人绝对路径和预选视频页面。Python工具的扩展路径按仓库根目录计算，独立调试配置存放在本机 `LOCALAPPDATA/YangmoLegacy/chrome-debug-profile`（无该环境变量时使用当前用户目录下的同名子目录）；启动页为 `about:blank`。这些默认值只用于脱敏，不表示历史工具已重新验证可用，也不代表历史实测使用了空白页。
